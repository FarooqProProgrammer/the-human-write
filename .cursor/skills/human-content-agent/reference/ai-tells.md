# AI tells — ban and swap

Prefer plain, specific wording. Context can make a word fine; empty use is the problem.

## Hard bans (almost never)

| Avoid | Prefer |
| --- | --- |
| delve / dive deep | look at, unpack, get into |
| in today’s fast-paced world | (delete; start with the point) |
| it’s important to note | (delete or state the fact) |
| unlock (metaphor) | open, enable, get |
| tapestry | mix, range, set |
| landscape (metaphor) | market, field, space (only if concrete) |
| leverage | use |
| utilize | use |
| robust | reliable, solid, strong (with proof) |
| seamless | smooth, without handoffs |
| cutting-edge / state-of-the-art | new, current—or name the tech |
| game-changer / revolutionary | say what changed |
| embark on a journey | start, try, build |
| at the end of the day | (delete; make the point) |
| moreover / furthermore | (delete or use “and”) |
| nestled / realm / beacon | (rewrite plainly) |
| testament to | shows, proves |
| fosters / empowers | helps, lets, supports |
| streamline | simplify, speed up |
| holistic | full, whole, end-to-end (if true) |

## Patterns to cut

- **Empty superlatives** — best-in-class, unparalleled, world-class → replace with a specific benefit or drop
- **Rule of three padding** — three parallel nouns that add no information → keep one strong point
- **Em dash addiction** — one occasional dash is fine; stacks of them read generated
- **Same sentence opener** — “This… This… This…” or “It’s… It’s…” → vary or merge
- **Hedging stacks** — “can help potentially enable” → one clear verb
- **Fake ranges** — “from X to Y to Z” when items aren’t a real range
- **Vague attributions** — “experts say,” “studies show” without a source → flag in reference file or remove
- **Generic closers** — “In conclusion, the future is bright” → concrete next step
- **Chatbot residue** — “I hope this helps,” “Let me know if you’d like,” unless the user wants a collaborative close

## Quick self-check before deliver

1. Could this open belong to any brand or topic? If yes, make it more specific.
2. Any sentence that only sounds smart without saying anything? Cut it.
3. Any claim that needs a number, name, or source you don’t have? Flag it—don’t invent.
